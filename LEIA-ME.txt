ALVES FINANCIADOR — PROJETO ANDROID 2.0

Projeto Android nativo (Kotlin + WebView local), com identidade visual e logo ALVES FINANCIADOR. O painel funciona offline e armazena os dados localmente no aparelho.

RECURSOS DA VERSÃO 2.0
- Painel com saldo do mês, receitas, despesas e dívidas em aberto.
- Lançamento de receitas e despesas com descrição, valor e data.
- Cadastro de dívidas, vencimento, taxa mensal informativa e registro de pagamentos.
- Metas financeiras com acompanhamento do valor acumulado.
- Exportação e restauração de backup JSON.
- Interface responsiva para celular e tablet.

IMPORTANTE
Este pacote contém o PROJETO-FONTE. Não foi possível compilar o APK neste ambiente porque Android SDK/Gradle não estão instalados aqui.

GERAR O APK PELO GITHUB
1. Envie o conteúdo desta pasta para a raiz do repositório GitHub.
2. Abra a aba Actions.
3. Execute o workflow "Build ALVES FINANCIADOR APK" ou faça push na branch main.
4. Ao concluir, baixe o artefato "ALVES-FINANCIADOR-APK".
5. Extraia app-debug.apk e instale no Android. Se solicitado, permita instalar apps desta fonte.

ATENÇÃO AOS DADOS
Os registros ficam salvos no armazenamento local do aplicativo. Use a área Backup para exportar uma cópia antes de trocar de celular ou reinstalar. Limpar os dados do app pode apagar os registros locais.
